# Counter App

A simple Counter App built using HTML, CSS, and JavaScript.

## Features

- Increase counter
- Decrease counter
- Reset counter
- Dynamic color changes:
  - Green for positive values
  - Red for negative values
  - White for zero

## Technologies Used

- HTML
- CSS
- JavaScript

## Concepts Learned

- Variables
- Functions
- DOM Manipulation
- Event Listeners
- Conditional Statements
- Dynamic Styling
- Git & GitHub Workflow

## How To Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` using Live Server
